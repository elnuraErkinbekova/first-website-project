# TutorKey - Online Tutoring Website

TutorKey is a frontend-only website created for learning and practicing HTML, CSS, and JavaScript. It is not a real service, and none of the features (signup, course access, pricing plans) are functional.

## Features
- Responsive navigation bar
- "Courses" page showcasing the reason for choosing TutorKey
- "Pricing" page with different subscription plans
- "Sign Up" section for users to enter their details (non-functional, for visual purposes)

## Project Structure
```
/ TutorKey
│── index.html       # Homepage
│── pricing.html     # Pricing plans page
│── courses.html     # TutorKey overview page
│── signup.html      # Sign-up section
│── styles.css       # Main stylesheet
│── app.js           # JavaScript functionality
│── README.md        # Project documentation
```

## How to Run the Project
1. **Clone the repository:**
   ```sh
   git clone https://github.com/your-username/tutorkey.git
   ```
2. **Navigate to the project folder:**
   ```sh
   cd tutorkey
   ```
3. **Open `index.html` in your browser:**
   - You can simply double-click the `index.html` file.
   - Or use a local development server like Live Server in VS Code.

## Technologies Used
- **HTML** – Structure of the website
- **CSS** – Styling and responsiveness
- **JavaScript** – Navigation bar toggle & pricing switch
- **Font Awesome** – Icons for better visuals
